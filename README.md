# SaveVault — Preset & Config Central

Проект лабораторной работы по веб-разработке.

## Структура проекта:
- `index.html` — Главная страница и интерфейс модальных окон.
- `data.json` — Файл базы данных в формате JSON (содержит список пресетов/ссылок и учетные записи).
- `css/style.css` — Стили оформления (шрифты, скроллбары, системные классы).
- `js/app.js` — Вся логика работы с БД, авторизация, фильтры, CRUD и LocalStorage.

## Как запустить:
Распакуйте архив и откройте `index.html` в браузере (желательно через локальный веб-сервер, например Live Server в VS Code, или просто двойным кликом).
